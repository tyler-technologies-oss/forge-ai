The AI Artifact Card component displays a compact, clickable card representing an artifact an agent produced — a
query result, a report, a generated document. Activating it emits an event; the consumer decides what opens.

The component is presentational. It holds no knowledge of what the artifact is, where it lives, or what happens
when it is opened.

<Canvas of={AiArtifactCardStories.Demo} />

## Features

- **Whole-card click target**: the entire card is a single native button, so clicking the icon, the text, or empty space all activate it
- **Truncating text**: both lines truncate to a single line rather than wrapping or growing the card
- **Active state**: renders a ring when the artifact is the one currently being viewed
- **Consumer-owned icon and label**: both arrive by slot, so no icon set or label vocabulary is baked in
- **Themeable accent**: one custom property colors the icon, the action label, and the active ring together

## Active state

The card does not decide when it is active — the consumer sets the `active` attribute. This keeps the component
usable whether selection state lives in a store, a router, or nowhere at all.

## Accessibility

- The whole card is a single `<button>`, so its accessible name is composed from its text content
- The icon is decorative and marked `aria-hidden="true"`
- **The `action` slot must contain text, not an icon alone.** That label is the only non-color signal
  distinguishing one card from another — an icon-only action leaves screen reader and colorblind users with no way
  to tell a query card from a report card
- Prefer keeping the type in the active label ("Viewing report" over "Viewing"), or the distinction is lost exactly
  when users are comparing cards
- Keyboard activation via Enter and Space comes from the native button; focus shows a visible ring on keyboard
  focus only, not on mouse click
- The card does not animate on mount, so consumers rendering a list of them do not replay motion on unrelated
  state changes
